# Mobile Dependency Security Exceptions

**Date:** 2026-10-28  
**Toolchain:** Expo SDK 58 / React Native 0.88  
**Review deadline:** 2026-11-15

## Policy

Mobile CI fails on any high- or critical-severity npm advisory unless the advisory is explicitly listed in `scripts/security-audit.cjs` and the exception has not expired.

Exceptions are advisory-specific, package-specific, and time-bounded. A new advisory ID, a critical advisory, a different affected package, or an expired exception fails CI.

## Current temporary exceptions

| Advisory | Package | Severity | Reason for temporary exception |
| --- | --- | --- | --- |
| `GHSA-mrhx-c7xc-m3w5` | `zod` | High | Expo SDK 58's `@expo/cli` depends on `zod ^3.25.76` and installs a private copy (`node_modules/expo/node_modules/zod`). The fix requires zod 4.6.6+, which the CLI does not support; npm's suggested remediation downgrades to Expo 51. |

`npm audit` also lists `@expo/cli` and `expo` as high. Those are the same zod finding reported up the dependency chain, not separate advisories; the gate evaluates advisory IDs, so they need no entry.

The zod copy runs only inside the Expo CLI on developer machines and in CI, where it validates the repository's own project configuration. It is not bundled into the iOS or Android app and never processes end-user input. The application's own top-level `zod` is already 4.6.7.

## Remaining low advisories

`deepmerge` (`GHSA-gcqx-w48m-w2h4`, 11 low findings) is reached through `@expo/config` and `jest-config` — build and test tooling that merges the project's own configuration. It stays visible in audit output and is re-evaluated at the next Expo or Jest upgrade.

## Removal criteria

Remove the zod exception immediately when any of the following becomes true:

1. an Expo SDK 58 release ships `@expo/cli` on zod ≥ 4.6.6,
2. Samgamam application code starts using the Expo CLI's zod copy or passes untrusted input to Expo CLI config validation,
3. the review deadline is reached.

No exception in this file authorizes ignoring a critical advisory.
